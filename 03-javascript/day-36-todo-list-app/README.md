# Todo List App

This is a JavaScript Todo List App built as part of my MERN Stack learning journey.

## Features

- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Undo completed tasks
- Clear all tasks
- Clear completed tasks
- Filter all, pending, and completed tasks
- Search tasks
- Save tasks in localStorage
- Load saved tasks after page refresh
